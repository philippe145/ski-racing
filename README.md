# Where to Find Online Ski Racing Gear

A one-page directory of online stores for alpine ski racing gear in the USA and Canada:

- Race shops (race-stock skis and boots, GS suits, protection)
- Tuning and wax suppliers, gates and club supply
- National team kit for 2026/27 and where to buy it
- Base layers worn by national teams
- FIS cut-resistant base layers (mandatory at FIS Alpine races from 2026/27)
- Used race skis

Search by shop, team or brand (e.g. "Fischer", "Lange"). Information checked October 2026.

The whole site is `index.html`, with no build step. To publish it with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
